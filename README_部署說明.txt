美食冒險家 v2.5（2026-10-29）
================================

【資料夾內容】
  index.html      遊戲本體（單一檔案）
  music/          配樂 mp3（6 首，取自大橋大車拚，已壓縮成 112kbps）

【部署（建議）】
  Netlify：把整個資料夾直接拖進 Netlify 的 Deploy 區就完成。
  GitHub Pages：index.html 和 music 資料夾一起放進 repo 根目錄。
  ※ music 資料夾要跟 index.html 放在同一層，配樂才找得到。

【直接雙擊 index.html 可以玩嗎？】
  可以，但瀏覽器不允許本機網頁讀取 mp3，這時會自動改用內建的合成配樂。
  想聽正式配樂，請放到網站上（Netlify / GitHub Pages）再開。

【讓學生的角色動起來】
  1. 在 Tinkercad 做角色時，把「手」「腳」「頭頂的裝飾（帽子、皇冠）」做成分開的零件（不要群組成一塊）。
     遊戲會自動辨識：身體兩側的零件＝手，下方的零件＝腳，頭頂的零件＝配件。
  2. 角色正面朝 Tinkercad 的「前視圖」方向。
  3. 匯出：Tinkercad →「匯出」→「.OBJ」，會下載一個 zip，直接把 zip 拖進遊戲的「上傳我的角色」。
  4. 上傳後可以按「走路／跳躍／飄浮／攻擊／揮手／跳舞」預覽動作。
     拿著武器的手（比較長的那一邊）會負責攻擊揮砍。
  5. 角色記在這台電腦的瀏覽器裡，下次打開還在。

【操作】
  移動 ← →（A D）　跳／二段跳 空白鍵或 ↑（吃 🍭 棉花糖後 15 秒可一直飄）　吸入／攻擊 J（X）　吞下 ↓　丟掉能力 K（C）
  揮手／跳舞 E　暫停 P 或 Esc　手把：A 跳、X／B 吸入、Y 丟能力、Start 暫停
  平板與手機會自動出現觸控按鈕（設定裡可以強制顯示或隱藏）。

【內容】
  關卡：1 蒲公英草原、2 安平老街（中魔王 大劍士）、3 棉花糖雲海、4 花園夜市（中魔王 炎炎大王）、5 雷雲古堡（最終魔王 雷雲王）
  複製能力 6 種：火焰、冰凍、寶劍、石頭、電電、炸彈
  台南小吃 17 種：12 種特別能力＋5 種補給，吃過會收進「小吃圖鑑」
  每關評等 S／A／B／C：看星星收集率、有沒有失誤、過關時間

【存檔】
  進度、圖鑑、設定存在瀏覽器（localStorage），角色存在 IndexedDB。
  設定 →「清除進度」可以重來（角色不會被刪掉；要換回預設角色請在標題畫面按「用預設角色」）。
